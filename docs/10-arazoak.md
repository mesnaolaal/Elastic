# Ohiko akatsak eta arazo-konponketa

Edozein zerbitzu huts egiten badu, lehenengo begiratu bere log-a: `sudo journalctl -u ZERBITZUA -n 50 --no-pager`. Gero bilatu hemen.

| Sintoma                                                                                      | Kausa probablea                                                                            | Konponbidea                                                                                                                |
|----------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------|
| `curl: (60) SSL certificate problem`                                                         | CA ziurtagiria ez da adierazi                                                              | `--cacert /etc/elastic-ca/http_ca.crt` gehitu                                                                              |
| Filebeat, Logstash edo Heartbeat-en log-etan `x509: certificate signed by unknown authority` | CA ez dago konfiguratuta, edo erabiltzaileak ezin du fitxategia irakurri                   | `ssl.certificate_authorities` (Beats) edo `ssl_certificate_authorities` (Logstash) egiaztatu; fitxategiaren baimenak `644` |
| `401 Unauthorized`                                                                           | Pasahitza okerra edo keystore-an ez dago                                                   | `sudo filebeat keystore list`; pasahitza berrezarri `elasticsearch-reset-password` bidez                                   |
| Elasticsearch ez da abiarazten                                                               | Memoria gutxi edo heap handiegia                                                           | `free -h`, `heap.options` txikitu, `journalctl -u elasticsearch`                                                           |
| Kibana: *Kibana server is not ready yet*                                                     | Abiarazten ari da, edo Elasticsearch ez dago martxan                                       | Minutu bat itxaron; `journalctl -u kibana`                                                                                 |
| Kibana ez da irisgarri nabigatzailetik                                                       | `server.host`, suebakia edo sarea                                                          | `server.host: "0.0.0.0"`; `ufw allow 5601/tcp`; beste ekipo batetik sartzeko, IP helbidea                                  |
| Osagaiek bertsio desberdinak dituzte                                                         | Biltegi ezberdinak edo eguneratze partzialak                                               | `dpkg -l 'elasticsearch*' 'kibana*' 'logstash*' '*beat*'`                                                                  |
| A bidea: ebento bakar handi bat, edo dokumenturik ez                                         | `response.split.target` okerra                                                             | `body.sentsoreak` erabili                                                                                                  |
| A bidea: `sentsoreak-beats` ez da agertzen                                                   | Indize pertsonalizatuaren ezarpenak falta dira                                             | `setup.template.name`, `setup.template.pattern`, `setup.ilm.enabled: false`                                                |
| Filebeat-en log-an `Failed to index N events ... events were dropped!`                       | `balioa` eremuan mapaketak onartzen ez duen balio bat iristen da (adib. `"N/A"` float-ean) | Espero da A bidean: 3. galderaren oinarria; arrazoia ikusteko, erreproduzitu eskuz Dev Tools-en (`POST`)                   |
| Logstash ez da abiarazten                                                                    | Sintaxi-errorea edo fitxategi-baimenak                                                     | `--config.test_and_exit` `logstash` erabiltzailearekin; `/var/log/logstash/logstash-plain.log`                             |
| `_jsonparsefailure etiketa`                                                                  | Log-lerroa ez da JSON baliozkoa (nginx-en log_format okerra)                               | sudo tail -n 3 /var/log/nginx/access.log \| jq eta sudo nginx -t                                                           |
| `_dateparsefailure` etiketa                                                                  | Data-formatua okerra                                                                       | `match => ["ordua", "ISO8601"]```                                                                                          |
| Bigarren Filebeat: *data path already locked by another beat*                                | Bi instantziek `--path.data` bera dute                                                     | `/var/lib/filebeat-logak` erabili zerbitzuan                                                                               |
| `Unable to locate package heartbeat`                                                         | Paketearen izena desberdina da                                                             | `heartbeat-elastic` instalatu                                                                                              |
| Web simulatua ez dabil                                                                       | Ingurune birtualaren bidea edo Flask instalatu gabe                                        | `journalctl -u web-sentsoreak`; `./venv/bin/pip install flask`                                                             |
| Nginx-en bidez 502 Bad Gateway                                                               | Flask (web-sentsoreak) gelditua dago edo ez dabil                                          | sudo systemctl status web-sentsoreak; journalctl -u web-sentsoreak                                                         |
| nginx -t: duplicate default server                                                           | Lehenetsitako gunea oraindik aktibo dago                                                   | sudo rm -f /etc/nginx/sites-enabled/default                                                                                |
| `No such file or directory - /home/...` (`logstash-keystore` edo `--config.test_and_exit`)   | `sudo -u logstash` komandoak zure karpeta pertsonaletik exekutatu dira                     | `cd /usr/share/logstash` eta berriz exekutatu                                                                              |
| `AccessDeniedException: /etc/logstash/logstash.keystore`                                     | Keystore-a `logstash` erabiltzailearekin sortzen saiatu zarete                             | `sudo`-rekin sortu (ez `-u logstash`), gero `chown logstash:root` eta `chmod 0600`                                         |
| `web-sentsoreak`: `status=2` / `Start request repeated too quickly`                          | `web_sentsoreak.py` ez dago `~/web` karpetan                                               | Fitxategia kopiatu; `sudo systemctl reset-failed web-sentsoreak` eta `restart`                                             |
| Kibana: `Invalid enrollment token`                                                           | `TOKENA_HEMEN` literala kopiatu duzue, edo tokena iraungi da (30 min)                      | Komando bakarra erabili (2. fasea)                                                                                         |
| 9200 edo 5601 portua okupatuta                                                               | Docker edukiontziak Elasticsearch/Kibana-rekin                                             | `docker stop $(docker ps -q)`                                                                                              |
| Dashboard-eko panela hutsik (`No results found`)                                             | Iragazki aktiboa (adib. `agent.type: filebeat`) edo denbora-tartea                         | Kendu iragazkia (x) eta zabaldu denbora-tartea                                                                             |
| Dev Tools: `match_only_text fields do not support sorting and aggregations`                  | `error.message` ezin da taldekatu                                                          | `_source` iragazkia edo `filter_path` erabili                                                                              |
| Discover: `this.requests.values().filter is not a function`                                  | Nabigatzaile zaharra (susmoa)                                                              | Nabigatzailea eguneratu edo beste bat erabili                                                                              |
